AgentTrust

AI agent security gateway · Oct 2026 · Winner, DecentraHack at PCCOE Akurdi

AI agents call tools. AgentTrust decides which calls are allowed, before they run, and keeps a record nobody can quietly edit.

  • Runtime authorization policies decide which tool calls an agent may make.
  • JWT authentication and credential revocation cut off access as soon as it is withdrawn.
  • Every security decision is written to an EVM smart contract, so anyone can verify the log.
  • Tested with a live LLM through its API, with the model’s tool calls passing through the gateway.
